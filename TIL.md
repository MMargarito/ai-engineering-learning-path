To day I learned the differences between an AI engineer/ML engineer/Data Scientist/Forward Deployed Engineer

AI engineers: Build LLM apps and agents using existing models to create software around them
Data Scientist: Study Data to answer buisness questions and sometimes train models to assit in answering those questions
ML engineers: Build Models and train them using math and ML/AI concepts. 
Forward Deployed Engineer: Similar to an AI Engineer except they are sent directly to their customer and work in their systems. They design custom solutions using existing products.

I also learned what an AI Engineer actually does. AI Engineers Build LLM apps and agents. The main difference is an LLM app only responds. Like a chatbot. An agent has agency. It doesn't need a clear pipeline in order to complete task. The agent can figure out on its own how to complete a task. After building those apps and agents they then Deploy those agents or apps so many users can use them. They finally make sure to test and evaluate the accuracy and function of the LLM app or agent. They do this my testing them through many scenarios where they can tangibly measure the accuracy and efficency of a system.
