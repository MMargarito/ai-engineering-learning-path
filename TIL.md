Today, I learned the differences between an AI Engineer, ML Engineer, Data Scientist, and Forward Deployed Engineer.

AI Engineer: Builds LLM apps and agents using existing models to create software around them.

Data Scientist: Studies data to answer business questions and sometimes trains models to assist in answering those questions.

ML Engineer: Builds and trains models using math and machine learning/AI concepts.

Forward Deployed Engineer: Similar to an AI Engineer, except they are sent directly to the customer and work within the customer's systems. They design custom solutions using existing products.

I also learned what an AI Engineer actually does. AI Engineers build LLM apps and agents. The main difference is that an LLM app only responds, like a chatbot, while an agent has agency. It doesn't need a clear pipeline to complete a task. An agent can figure out on its own how to complete a task.

After building those apps and agents, AI Engineers deploy them so that many users can access and use them. Finally, they make sure to test and evaluate the accuracy and functionality of the LLM app or agent. They do this by testing them through many different scenarios where they can tangibly measure the accuracy and efficiency of the system.
